## 1. Application Overview

### 1.1 Purpose
LoudspeakerFEA is a Finite Element Analysis (FEA) augmented desktop application that simulates traditional ceramic magnet woofer motors. It duplicates the functionality of the `[FEMotor]` worksheet in the reference Excel workbook (`reference_workbook.xls`), including all parametric calculations, voice-coil characterization, motor geometry derivation, loudspeaker parameter estimation, BL-versus-displacement curves, and side-leakage analysis.

The program drives the open-source **ElmerFEM** engine to perform the magnetic-field simulation and extracts results for display and further calculation.

### 1.2 Target User
Loudspeaker design engineers and technicians who need to predict motor performance (BL curve, flux density, side leakage, resulting Thiele-Small parameters) from physical motor dimensions and voice-coil specifications.

### 1.3 Key Value Proposition
- Replicates an existing Excel-based workflow exactly (same formulas, same outputs) in a standalone Windows desktop application.
- Eliminates Excel dependency while preserving the familiar calculation pipeline.
- Provides fast what-if analysis via an AI-agent-addressable API.
- Visualizes BL(x) and side-leakage curves interactively.

### 1.4 Platform
Windows 10/11 desktop application. Single-user, local execution.

### 1.5 Inferences (Explicit)
| # | Inference | Rationale |
|---|-----------|-----------|

## 2. UI Layout

The UI follows the **LoudspeakerDesigner** pattern:
- **Left panel**: fixed-width scrollable `QScrollArea` (~440 px) containing stacked `QGroupBox` widgets with `QFormLayout`. Each group contains `QDoubleSpinBox` inputs (white cells) and read-only `QLabel` outputs (cyan cells).
- **Right panel**: `QTabWidget` occupying remaining width, containing matplotlib plots and image display.
- **Menu bar**: File, Setup, Help.
- **Status bar**: Shows "Ready", "Running Elmer...", or error messages.

### 2.4 Right Panel Tabs

1. **BL(x) Curve** — Matplotlib plot of BL (T·m) vs displacement x (mm). X-axis: mm, Y-axis: BL (axis lower limit fixed at 0). Shows the full BL(x) data series from the Elmer sweep.
2. **Side Leakage** — Matplotlib plot of side leakage flux density vs angular position (or distance). Uses data from the Elmer post-processed contour integration.
3. **FEA Geometry** — Displays the B-field density plot generated from Elmer post-processing. The plot uses a **fixed color scale of 0–2 T** with **decimal tick labels** (e.g., 0.0, 0.5, 1.0, 1.5, 2.0) — **no scientific notation**.
4. **Sensitivity Analysis** *(optional, inferred)* — Allows varying a single parameter (e.g., top plate thickness) and viewing BL or sensitivity response.

### 2.5 Design Selector
At the top of the left panel (or in a toolbar), a `QComboBox` or `QSpinBox` selects the active design (1–8), matching the spreadsheet's column layout. Changing the design swaps all input/output values. A "Compare Designs" button opens a dialog showing key metrics side-by-side.

### 6.1 Elmer Integration Method
- The application writes an Elmer SIF file and mesh to the working directory.
- It launches `ElmerSolver.exe` via `subprocess.Popen` with the SIF file as input.
- The SIF defines a 2D axisymmetric `MagnetoDynamics2D` problem with the motor geometry (top plate, magnet, back plate/pole piece, coil air gap). No bucking magnet geometry is created.
- Materials are assigned via the SIF: Air, selected magnet material, China Steel (with full B-H curve), Ceramic5 (with full B-H curve).
- Mesh density is controlled by the `mesh_size_factor` setting.
- After solving, the Python process reads Elmer result files (VTU/EP) and extracts:
  - B-field at x=0 (voice coil rest position) via line integral or point probe
  - B-field at magnet center → `Bmagnet`
  - VC sweep: 61 positions from -Xmax to +Xmax, extracting B at each
  - Side leakage: contour integration at the specified measurement distance
- A matplotlib-generated B-field density plot is saved as `B-Field.png` with a **fixed color scale of 0–2 T** and **decimal tick labels** (no scientific notation).
- **Inference**: The exact Elmer solver keywords, boundary condition syntax, and result file format may differ from FEMM. The Coding Agent must verify the Elmer `MagnetoDynamics2D` SIF syntax and adapt the geometry-building logic accordingly. If any capability is unsupported, the agent must flag it in the gate result and request guidance.

### B.1 Geometry & Mesh Generation
1. Build the axisymmetric geometry in millimeters using the same node coordinates as the FEMM preprocessor.
2. Regions: top plate (China Steel), magnet (selected material), back plate/pole piece (China Steel), coil air gap (Air), surrounding air.
3. **No bucking magnet region** — skip all bucking-magnet nodes and segments.

### B.2 SIF Structure
1. `Header` — set mesh directory and results file.
2. `Constants` — permeability of vacuum.

4. `Body` — assign materials to geometric regions.
